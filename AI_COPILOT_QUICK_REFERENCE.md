# AI Copilot - Quick Reference Card

## 🎯 When Does It Appear?

```
❌ Before: Always visible
✅ After:  Only after generating recommendations
```

## 💬 How Does It Speak?

```
❌ Before: "I will switch to Spot instances"
✅ After:  "One option would be to switch to Spot instances"
```

## 🎛️ How Do You Apply Changes?

```
❌ Before: Accept/Reject all changes together
✅ After:  Select specific changes with checkboxes
```

## 📋 Response Structure

```
1. 💡 Suggestions (Advisory language)
2. 🔍 Impact Summary (Visual indicators)
3. 🔧 Optional Actions (Checkboxes)
4. ✅ Confirmation (Only if selections made)
```

## 🎨 Visual Design

```
Header:     48px height, Indigo-Purple gradient
Button:     56px circle, bottom-right
Messages:   24px spacing, 12px radius
Cards:      16px padding, soft borders
```

## 🔄 User Flow

```
1. Generate recommendations
2. AI button appears
3. Ask for suggestions
4. Review suggestions
5. Select changes (checkboxes)
6. Click "Apply Changes"
7. See toast notification
8. Check Activity log
```

## ✅ Key Features

- **Contextual**: Appears at the right time
- **Advisory**: Suggests, doesn't command
- **Granular**: Select individual changes
- **Conditional**: Confirmation only when needed
- **Feedback**: Toast + message + activity log

## 🎯 User Feeling

> "This AI is advising me, not forcing changes — and I stay in control."

---

**Quick Tip**: The copilot is a consultant, not an executor. You're always in control!
